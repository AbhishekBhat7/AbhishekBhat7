# 💫 About Me:
<br>I’m a **Software Engineer and Mobile Application Developer** with hands-on experience building and deploying scalable, production-ready applications across **mobile, backend, web, cloud, and IoT ecosystems**. I specialize in **Flutter and Dart** for cross-platform mobile development and have strong experience with **Node.js, Express.js, PostgreSQL, Microsoft Azure, Docker, and RESTful APIs**.<br><br>Over the course of my experience, I have worked on multiple **live Android and iOS applications**, developing solutions across **fitness and wellness, healthcare, trainer-athlete platforms, industrial machine control, e-commerce, visualization, and IoT**. I enjoy taking products from concept to production while focusing on performance, scalability, reliability, and a smooth user experience.<br><br>On the **mobile development** side, I work extensively with **Flutter, Dart, BLoC state management, Clean Architecture, responsive UI development, SQLite/sqflite, BLE, Wi-Fi communication, Mapbox APIs, Razorpay, Jitsi, and fl_chart**. I have developed applications involving **real-time Bluetooth Low Energy data streaming, wearable integrations, remote machine control, live performance analytics, offline-first functionality, maps, payments, video consultations, and real-time monitoring dashboards**.<br><br>On the **backend and server-side** side, I have built scalable services using **Node.js and Express.js**, developed and optimized REST APIs, implemented authentication and validation mechanisms, and worked with **PostgreSQL** for database management. I have experience designing backend systems that support real-time communication, concurrent sessions, mobile applications, and data-intensive workflows.<br><br>I also have practical experience with **Microsoft Azure, A2 Hosting, Docker, and CI/CD automation**, including deploying backend services, managing cloud infrastructure, and improving development and release workflows. In my current role, I have worked on automating deployment pipelines and improving release efficiency for production applications.<br><br>My experience also extends into **IoT and embedded systems**, including building **Flutter-based Raspberry Pi applications**, integrating Bluetooth and Wi-Fi communication, developing real-time device data streaming, and working with machine-control systems. I have also explored communication workflows through reverse engineering and built solutions requiring interaction between software and connected devices.<br><br>Some of the key technologies and tools I have worked with include:<br><br>**Mobile:** Flutter, Dart, BLoC, Clean Architecture, SQLite/sqflite, BLE, Wi-Fi<br>**Backend:** Node.js, Express.js, REST APIs, PostgreSQL<br>**Web:** HTML, CSS, JavaScript<br>**Cloud & DevOps:** Microsoft Azure, A2 Hosting, Docker, CI/CD<br>**Integrations:** Mapbox, Razorpay, Jitsi, Bluetooth Low Energy<br>**Visualization:** fl_chart, real-time dashboards<br>**IoT & Embedded:** Raspberry Pi, BLE devices, Wi-Fi-enabled systems<br>**Development:** API development, authentication, two-factor authentication, real-time systems, offline-first architecture, responsive UI, performance optimization, debugging, and production deployment<br><br>I have contributed to and developed applications such as **Wellwise Lifestyle Companion, Ayursetu Uplifting Wellness, Aikyam, and Nico**, along with several other full-stack mobile and web projects.<br><br>I’m particularly interested in solving real-world engineering problems, building scalable products, integrating software with hardware, and continuously learning new technologies. My goal is to build **reliable, high-performance, and user-focused software** while growing as a versatile engineer across mobile, backend, cloud, and emerging technologies.<br>
